# Thanksgiving

A Claude Code mod with a cozy Thanksgiving den: a crackling fireplace, the big game on TV, and a big feast that gets eaten as the context window fills.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install thanksgiving --marketplace shannoj/thanksgiving-mod
```

Answer `y` to add the marketplace, then pick a scope (user is first; press Enter).

From a shell:

```bash
claude plugin install thanksgiving --marketplace shannoj/thanksgiving-mod
```

In the Claude desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `shannoj/thanksgiving-mod`, then Add plugin.
